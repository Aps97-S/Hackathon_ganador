Stock & Cryptocurrency Tracker - Guia d'Administrador

Visió General

Aquesta guia proporciona instruccions als administradors del sistema per a desplegar, mantenir i gestionar l'aplicació Stock & Cryptocurrency Tracker. L'aplicació és una solució client-side construïda amb HTML, CSS i JavaScript.

Requisits del Sistema

Requisits de Maquinari

  • Qualsevol ordinador o servidor modern capaç d'executar un navegador web
  • Mínim 512MB RAM (recomanat 1GB+)
  • 10MB d'espai disponible en disc per als fitxers de l'aplicació

Requisits de Programari

  • Servidor web (Apache, Nginx o servidor HTTP simple)
  • Navegador web modern per a proves
  • Git (per al control de versions i actualitzacions)

Instruccions d'Instal·lació

Prerequisits

# Instal·la un servidor web (exemple utilitzant Apache a Ubuntu/Debian)
sudo apt update
sudo apt install apache2

# O utilitza http-server de Node.js per proves ràpides
npm install -g http-server

Passos de Desplegament

  1. Baixa l'Aplicació: 
    # Clona o descarrega el repositori
git clone <repository-url>
cd stock-crypto-tracker
  2. Copia els Fitxers al Directori del Servidor Web: 
    # Copia els fitxers al directori arrel del servidor web (ex: /var/www/html/)
sudo cp -r ./* /var/www/html/

# O per a proves locals, simplement posa els fitxers en una carpeta
  3. Estableix Permisos Apropiats: 
    # Assegura't que el servidor web pugui llegir els fitxers
sudo chown -R www-data:www-data /var/www/html/
sudo chmod -R 755 /var/www/html/

Executant l'Aplicació

Proves Locals

# Mètode 1: Utilitzant el servidor HTTP integrat de Python (si està disponible)
python3 -m http.server 8000

# Mètode 2: Utilitzant http-server de Node.js
http-server

# Mètode 3: Utilitzant Apache/Nginx (configura un virtual host si cal)

Desplegament en Producció

  1. Configura el teu servidor web: 
    # Exemple de configuració d'Apache
<VirtualHost *:80>
    DocumentRoot /var/www/html/
    ServerName stocktracker.example.com
    
    <Directory "/var/www/html/">
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
  2. Reinicia el servidor web: 
    sudo systemctl restart apache2  # Ubuntu/Debian
sudo systemctl restart nginx    # CentOS/RHEL

Estructura de Fitxers

stock-crypto-tracker/
├── index.html          # Pàgina principal de l'aplicació
├── styles.css          # Estil CSS
├── script.js           # Funcionalitat JavaScript
├── USER_GUIDE.md       # Documentació d'usuari
└── ADMIN_GUIDE.md      # Documentació d'administrador

Opcions de Configuració

Emmagatzematge al Navegador

L'aplicació utilitza l'emmagatzematge local del navegador per persistir les alertes entre sessions. Això no requereix configuració al servidor.

Consideracions de Seguretat

  • Com que aquesta és una aplicació client-side, no hi ha preocupacions de seguretat al servidor
  • Tot el processament de dades es fa al navegador de l'usuari
  • No s'emmagatzena informació sensible als servidors

Manteniment i Actualitzacions

Tasques de Manteniment Regular

  1. Monitoratge del Rendiment de l'Aplicació: 
    # Comprova si el servidor web s'està executant
sudo systemctl status apache2

# Monitoritza l'espai en disc
df -h
  2. Actualització dels Fitxers de l'Aplicació: 
    git pull origin main
# O descarrega els fitxers actualitzats manualment
  3. Còpia de Seguretat de la Configuració (si n'hi ha): 
    # No calen fitxers de configuració per a aquesta aplicació

Actualització de l'Aplicació

# Navega al directori de l'aplicació
cd /var/www/html/

# Obtén la última versió del repositori
git pull origin main

# O reemplaça els fitxers manualment amb versions actualitzades

Monitoratge i Registre

Monitoratge de l'Aplicació

Com que aquesta és una aplicació client-side:

  • No hi ha registres al servidor per monitorar
  • Els interaccions d'usuari poden ser seguides mitjançant analítiques del navegador si s'integren
  • El monitoratge de rendiment hauria de centrar-se en el rendiment del servidor web

Optimització del Rendiment

  1. Assegura't que el servidor web estigui configurat per l'entrega de fitxers estàtics
  2. Considera habilitar la compressió GZIP per als fitxers CSS/JS
  3. Monitoritza la consola del navegador per a errors de JavaScript

Solucionador de Problemes

Problemes Comuns i Solucions

1. Aplicació No S'Està Carregant

Símptomes: Pàgina en blanc o error "Fitxer no trobat"

Solució:

# Comprova els permisos dels fitxers
ls -la /var/www/html/

# Verifica que els fitxers existeixin
ls -la /var/www/html/index.html

# Reinicia el servidor web
sudo systemctl restart apache2

2. JavaScript No Funciona

Símptomes: Cap actualització en viu, alertes no funcionant

Solució:

  • Comprova la consola del navegador per a errors de JavaScript
  • Assegura't que JavaScript estigui habilitat al navegador
  • Verifica que tots els fitxers s'hagin copiat correctament i siguin accessibles

3. Les Alertes No Persisteixen

Símptomes: Les alertes desapareixen després de refrescar la pàgina

Solució:

# Comprova si l'emmagatzematge local està habilitat al navegador
# Aquest és un problema a nivell de navegador, no d'aplicació

Millors Pràctiques de Seguretat

Per a la Seguretat del Servidor Web

  1. Mantingues el Servidor Web Actualitzat: 
    sudo apt update && sudo apt upgrade
  2. Securitza els Permisos dels Fitxers: 
    # Fes que els fitxers siguin llegibles però no executables
sudo chmod 644 /var/www/html/*.html
sudo chmod 644 /var/www/html/*.css
sudo chmod 644 /var/www/html/*.js
  3. Habilita HTTPS (recomanat): 
    # Instal·la un certificat Let's Encrypt
sudo apt install certbot python3-certbot-apache
sudo certbot --apache -d stocktracker.example.com

Còpia de Seguretat i Recuperació

Backup de l'Aplicació

# Crea una còpia de seguretat dels fitxers de l'aplicació
tar -czf stock-tracker-backup-$(date +%Y%m%d).tar.gz /var/www/html/

# O utilitzant rsync
rsync -avz /var/www/html/ backup-location/

Procés de Recuperació

  1. Copia els fitxers de còpia de seguretat al directori del servidor web
  2. Restaura els permisos de fitxers apropiats
  3. Reinicia el servidor web si cal

Ajustament del Rendiment

Optimització del Servidor Web

  1. Habilita la Compressió: 
    # Afegeix a la configuració d'Apache
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/css application/javascript
</IfModule>
  2. Posa en Caché els Fitxers Estàtics: 
    # Afegeix a la configuració d'Apache
<FilesMatch "\.(css|js)$">
    Header set Cache-Control "max-age=31536000, public"
</FilesMatch>
