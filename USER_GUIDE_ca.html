Stock & Cryptocurrency Tracker - Guia d'Usuari

Visió General

Aquesta aplicació proporciona un tauler de seguiment en temps real per a preus d'accions i criptomonedes. Els usuaris poden seleccionar els seus actius preferits, establir alertes de compra/venda i monitoritzar els moviments de preus amb indicadors visuals.

Característiques

  • Seguiment de Preus en Temps Real: Actualitzacions en viu dels accions i criptomonedes seleccionats
  • Selecció d'Actius: Tria entre accions populars (Apple, Google, Microsoft, Amazon, Tesla) i criptomonedes (Bitcoin, Ethereum, Ripple, Litecoin, Cardano)
  • Sistema d'Alerta: Estableix límits de compra/venda amb notificacions visuals
  • Disseny Responsiu: Funciona en dispositius d'escriptori i mòbils

Com Engegar

  1. Prerequisits:
    • Navegador web modern (Chrome, Firefox, Safari, Edge)
    • No es requereix instal·lació de programari addicional
  2. Executant l'Aplicació:
    • Obre index.html en qualsevol navegador web
    • El tauler es carregarà automàticament

Utilitzant el Tauler

1. Selecció d'Actius

  • Selecciona accions o criptomonedes dels menús desplegables
  • Fes clic a "Actualitzar Selecció" per aplicar les teves opcions
  • Els actius seleccionats apareixeran a la secció de seguiment a continuació

2. Seguiment de Preus

  • Els preus s'actualitzen cada 3 segons amb fluctuacions simulades
  • Indicadors verds mostren augment de preus
  • Indicadors vermells mostren disminució de preus

3. Establint Alertes

  • Introdueix un preu objectiu al camp "Establir Alerta"
  • Tria tipus "Compra" o "Venda"
  • Fes clic a "Establir Alerta" per crear una nova alerta
  • Les alertes es mostraran amb notificacions visuals quan s'activin

4. Gestió d'Alertes

  • Fes clic al botó "Eliminar" al costat de qualsevol alerta per suprimir-la
  • Totes les alertes es guarden a l'emmagatzematge local del navegador

Components de la Interfície

Secció de Capçalera

  • Títol i descripció de l'aplicació

Secció de Selecció d'Actius

  • Menús desplegables per seleccionar accions i criptomonedes
  • Botó d'actualització per aplicar les seleccions

Secció de Seguiment en Vida

  • Mostra els preus actuals dels actius seleccionats
  • Mostra els canvis de preu amb indicadors visuals

Secció d'Alertes

  • Llista totes les alertes de compra/venda actives
  • Mostra preus objectiu i tipus d'alerta
  • Notificacions visuals quan s'assolixin els objectius

Solucionador de Problemes

Problemes Comuns

  1. Els preus no s'actualitzen:
    • Assegura't d'estar utilitzant un navegador modern
    • Comprova que JavaScript estigui habilitat al teu navegador
  2. Les alertes no apareixen:
    • Verifica que el preu objectiu s'hagi establert correctament
    • Comprova que els preus dels actius estiguin fluctuant
  3. Problemes de compatibilitat amb el navegador:
    • Intenta obrir-ho en un navegador diferent
    • Assegura't que el teu navegador estigui actualitzat
